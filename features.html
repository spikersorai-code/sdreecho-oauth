Features

Highlight detection

Transcript and audio-energy analysis selects the strongest moments of a stream.

Facecam-aware layout

The streamer's camera panel is detected and placed above the gameplay in a 9:16 frame.

Captions

Word-by-word Turkish and English captions with consistent, readable styling.

Content filter

Clips with repeated profanity or without the streamer on camera are excluded.

Scheduling

One clip at a time on a fixed schedule, so the account is never flooded.

Direct Post

Publishing through TikTok's official Content Posting API, including publish status checks.

Duplicate protection

A publish log guarantees each clip is posted only once per platform.

Revocable access

Access tokens are kept on the server in a file readable only by the service account and are deleted when access is revoked.
